# starline-catalog – демо-каталог охранных комплексов StarLine

Чат «Старлайн», начат 14.10.2026. Задача владельца: каталог только охранных комплексов
(без категорий и «Защитить»), фильтр по функциям, сравнение, карточка товара с комплектациями
(метка / без метки и т.д.), без сопутствующих товаров. Источник – store.starline.ru/catalog/avtosignalizatsii/.

Стек: Astro 7 + Preact-острова, чистый CSS (src/styles/global.css – единственный файл стилей).
Демо: https://tema-mail.github.io/starline-catalog/ (GitHub Pages, workflow .github/workflows/pages.yml, noindex).

## Данные
- Сырые: `data/raw/` – снимаются `scripts/scrape_catalog.py`, `scrape_cards.py`, `scrape_compare.py` (в этом порядке, аргумент `data/raw`).
- Сайт: `npm run data` → `src/data/catalog.json` + `public/img/*.webp` (sharp). Руками json не править.
- Оси комплектаций (автозапуск, метки, BT, брелок, CAN, связь, GPS, реле) считает build_data.py.
  Метки/брелок – по составу коробки, связь – по названию: в матрице сравнения StarLine есть ошибки.
- Семейства – регулярки FAMILIES в build_data.py; ближайший вариант – resolve() в src/lib/catalog.ts.

## Правила
- Каталог: на телефоне 2 карточки в ряд, с 1024 px – 3, с 1280 px – 4; в каждой строке фильтра чип «Все» первым.
- Не писать «в наличии» и не делать кнопку «Купить» без реального заказа.
- Проверка перед коммитом: `npx astro build` + Playwright-прогон карточек (нет ошибок консоли и горизонтальной прокрутки на 390 px).
